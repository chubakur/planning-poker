# 🃏 Planning Poker

Командная оценка задач (planning poker) в реальном времени. Полностью статическое
приложение: работает прямо в браузере, без регистрации и без своего сервера.

**Живая версия:** https://chubakur.github.io/planning-poker/

## Возможности

- Создание сессии одной кнопкой и общий доступ по ссылке (без регистрации).
- Выбор колоды: Фибоначчи, Modified Fibonacci, последовательные, T-shirt, степени 2
  или свои карточки.
- Участник вводит только имя.
- Админ задаёт задачу и запускает голосование; оценки синхронизируются мгновенно
  через WebSocket.
- «Вскрыть карты» с показом оценок, средним/мин/макс и индикатором совпадения.
- Если оценки разошлись: переголосовать по задаче или выставить оценку вручную.
- Переход к новой задаче и история оценок сессии.

## Как это устроено

- `index.html` — разметка и стили.
- `app.js` — вся логика (vanilla JS, без сборки).
- `vendor/mqtt.min.js` — MQTT-клиент поверх WebSocket.
- Хостинг: GitHub Pages (статика).
- Транспорт: публичные MQTT-over-WebSocket брокеры (EMQX / HiveMQ / Mosquitto),
  перебор по очереди при недоступности.
- Приватность: каждое сообщение шифруется AES-256-GCM ключом, который лежит в
  фрагменте ссылки (`#...&k=...`). Фрагмент не отправляется серверу и не попадает
  в referer, поэтому брокер видит только шифротекст и случайный идентификатор комнаты.

## Локальный запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Ограничения

- Это клиент-клиентская синхронизация через публичный брокер: подходит для оценки
  задач в узком кругу, но не хранит данные на сервере.
- Значения карт скрыты в интерфейсе до вскрытия. Участник с доступом к ссылке
  теоретически может разобрать трафик, поэтому не используйте для секретных данных.
- Для полностью приватного контура положите `app.js` на любой WebSocket-сервер
  вместо публичного брокера (интерфейс транспорта изолирован).
